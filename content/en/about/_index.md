## Introduction

I’m a Cloud / DevOps Engineer focused on building dependable infrastructure and exploring practical AI engineering patterns. This site is a working portfolio: it records technical decisions, implementation notes, and lessons that are useful to revisit and share.

## Technical focus

- AWS cloud architecture and operational foundations
- Terraform, CloudFormation, and Infrastructure as Code
- DevOps, CI/CD, and GitHub Actions
- Cloud security and least-privilege design
- AI Engineering and Retrieval-Augmented Generation (RAG) applications

## Engineering philosophy

I value clear boundaries, repeatable automation, secure defaults, and designs that are understandable to the next engineer. Good infrastructure should be observable, economical to operate, and easy to change deliberately.

## Interests

Current areas of interest include AWS architecture patterns, infrastructure automation, delivery workflows, security trade-offs, and the engineering practices that make RAG applications more useful and reliable.
